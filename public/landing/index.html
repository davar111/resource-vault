Возможности

06 фич
01
Быстрое сохранение
Вставь URL — Vault сам получит название и превью. Никаких обязательных полей.
02
Умный поиск
Поиск по URL, названию, тегам и заметкам одновременно. Результаты мгновенно.
03
Коллекции
Организуй ссылки в папки. Делай общими для совместного доступа.
04
Автотеги
Автоматически определяет тип контента и ставит теги по домену и заголовку.
05
Скрытые ссылки
Личный раздел с паролем для ссылок которые не должны быть видны другим.
06
Синхронизация
Данные в Supabase — доступны с любого устройства после входа через Google.
Space — режим разбора

Ссылки не должны умирать в закладках

Каждый день Space показывает одну ссылку из прошлого — ту что ты забыл открыть. Два действия: открыть или архивировать. Стрик за ежедневный разбор.
