# Memory Bank

Эта папка хранит рабочий контекст проекта для быстрых и безопасных итераций.

## Правила

- Перед изменениями читать:
  - `memory-bank/project-context.md`
  - `memory-bank/current-focus.md`
  - `memory-bank/known-issues.md`
  - `memory-bank/decisions.md`
- После каждого изменения обновлять только релевантные файлы.
- Записи делать кратко, с датой и конкретикой.

## Состав

- `project-context.md` — что за проект, стек, ключевые зоны.
- `current-focus.md` — что делаем сейчас и следующий шаг.
- `known-issues.md` — подтвержденные проблемы и статус.
- `decisions.md` — принятые решения и причины.
- `change-log.md` — журнал внесенных изменений.

## Быстрый шаблон записи

```text
Дата: YYYY-MM-DD
Файл: memory-bank/<name>.md
Изменение: что сделано (1-2 строки)
Причина: зачем это нужно (1 строка)
Следующий шаг: что делаем дальше (1 строка)
```

Пример:

```text
Дата: 2026-02-22
Файл: memory-bank/current-focus.md
Изменение: Обновлен активный этап и список ближайших задач.
Причина: Чтобы не терять контекст между итерациями.
Следующий шаг: После следующей правки обновить decisions.md.
```
