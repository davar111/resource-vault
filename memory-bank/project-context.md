# Контекст проекта

Обновлено: 2026-02-22

## Проект

- Название: `resource-vault`
- Назначение: управление ссылками, коллекциями, фильтрами, onboarding.
- Технологии: Vanilla JS, Vite, CSS, Supabase.

## Ключевые файлы

- `src/main.js` — оркестрация состояния, событий, модалок, auth.
- `src/ui.js` — рендер UI (карточки, коллекции, фильтры).
- `src/styles.css` — основная стилизация и адаптив.
- `index.html` — разметка и модалки.

## Критичные UX-зоны

- Сетка карточек и производительность рендера.
- Мобильная навигация и топбар.
- Доступность модалок и клавиатурные сценарии.
